Optional AI

AI with a bill you control.

Dealflow works without AI. Add an OpenRouter key and set a company cap, plus an optional per-user cap.

Your key, your model

Connect OpenRouter and choose the model. The default is DeepSeek v4.1 Flash. No key means no AI, and nothing leaves your server.

Caps that hold

A company monthly token cap and an optional per-user cap. Every call is logged, and calls over a cap are refused.

Access-aware answers

The assistant uses MCP tools, sees only what the user can see, and asks before it writes.

Self-hosted

Your CRM, on your hardware.

One Compose stack: the app, a WebSocket server, a worker, Postgres and MinIO. Your records and files stay in your database and your bucket.

Install in a few minutes

$ git clone https://github.com/itchyparrot53/dealflow.git
$ cd dealflow
$ cp .env.example .env
$ # set BASE_URL, NEXT_PUBLIC_WS_URL, MINIO_ENDPOINT,
$ # SEED_ADMIN_EMAIL and the generated secrets
$ docker compose up -d --build

Open http://localhost:3000. With SMTP unset, the sign-in link prints in the app log. On a fresh box, mint the first admin setup link:

$ docker compose exec app node dist/bootstrap-link.mjs Copied

What you need

  • Docker Engine with the Compose plugin
  • A domain, and a second s3. hostname for storage
  • A reverse proxy for HTTPS, such as Caddy
  • Optionally, an SMTP account and an OpenRouter key

Questions, answered.

Is Dealflow free?

Yes. It is MIT licensed, with no paid tier and no per-seat fee.

Is there a hosted version?

No. Dealflow runs on your server. There is no Dealflow cloud and no account to create with us.

Is it multi-tenant?

No. One install serves one company. If you need separate companies, run separate instances.

What does it need to run?

Docker Engine with the Compose plugin, a domain and a second s3. hostname for storage, and a reverse proxy for HTTPS. Postgres and MinIO run in the Compose stack.

Do I need AI?

No. Without an OpenRouter key every AI surface is unavailable and nothing leaves your server. With a key, you set a company cap and an optional per-user cap.

How does email work?

Connect Gmail through Google OAuth, or any IMAP/SMTP mailbox with an app password. Campaigns use a separate sending account when you configure one, and fall back to your system SMTP.

Can I import from Pipedrive?

Contacts and leads can come in by CSV, and the REST API can write deals and other records. There is no one-click Pipedrive migration.

How do backups work?

The worker writes a daily archive with the database dump, stored files and a manifest. Restore from the CLI with the app stopped, and deleted records sit in a 30-day recycle bin.

Is it ready for production?

Dealflow runs a real business-development workflow in production and is actively developed. Back up your data and pin a release before upgrading.

Does it support SSO?

Google Workspace SSO when its three environment variables are set. Email and password and single-use email links work without Google.

Is Dealflow affiliated with Pipedrive?

No. Dealflow is an independent open-source project and is not affiliated with, endorsed by or connected to Pipedrive.
