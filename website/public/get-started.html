Requirements

What you need

  • A Linux server with Docker and the Docker Compose plugin
  • A domain for the app and a second one for file storage
  • A reverse proxy that handles HTTPS, such as Caddy or nginx
  • An SMTP account for sign-in links, invites and notifications
  • Optional: an OpenRouter API key for the AI features

Install

Up and running in five steps

  1. Copy the example settings

    cp .env.example .env

  2. Fill in your settings

    Set BASE_URL, NEXT_PUBLIC_WS_URL, MINIO_ENDPOINT, SEED_ADMIN_EMAIL, your SMTP_* account and, for AI, OPENROUTER_API_KEY.

  3. Generate the secrets

    openssl rand -base64 32   # TOKEN_ENCRYPTION_KEY
openssl rand -hex 32      # WS_TICKET_SECRET
openssl rand -hex 16      # MINIO_ACCESS_KEY and MINIO_SECRET_KEY

  4. Start everything

    docker compose up -d --build

  5. Sign in as the first admin

    Open your app address, choose Email link and enter the SEED_ADMIN_EMAIL address. Then invite your team from Settings › Users.

Reverse proxy

Three routes to point at Dealflow

Dealflow does not include a proxy, so it fits whatever you already run. Keep the ports bound to 127.0.0.1 so only your proxy can reach them.

Public addressSend toUsed for
https://crm.example.com127.0.0.1:3000The app
https://crm.example.com/_ws127.0.0.1:8080Live updates (WebSocket)
https://s3.crm.example.com127.0.0.1:9000File uploads and downloads

Check it with curl -fsS https://crm.example.com/api/health, which answers {"ok":true}.

Backups

Daily backups, restored from the server

Dealflow backs up the database and stored files every day and keeps them for as many days as you choose. Admins can check the status and run an extra backup from Settings. Restoring is done on the server, never from the browser.
